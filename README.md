# Algorithmic Bias in Loan Approval Decision-Making

## Project Overview
This project investigates whether protected attributes such as gender, age, race/ethnicity, and region influence loan approval outcomes generated by machine learning models.

## Study Objective
The study evaluates fairness and potential algorithmic bias in AI-driven loan approval systems.

## Methodology
Machine learning techniques are applied to a loan approval dataset to analyze predictive outcomes and fairness across demographic groups.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Files Included
- DKITPGDip-MainProject.ipynb
- Loan_Access.csv

## Purpose
This repository supports a dissertation on fairness and bias in machine learning-based loan approval systems.
